# Art prompts for the Merge Quest home screen

For ChatGPT image generation (gpt-image). Attach the home-screen mockup to the first message, run the **Style lock**, then send each prompt in the same chat so the style stays consistent.

Tips:
- Ask for one thing per image (or one sheet for icons). Regenerate until the edges are clean.
- Transparent backgrounds from chat are often fake (a checkerboard is painted in). Safer: ask for a flat solid **#FF00FF magenta** background, then remove it with a free tool (remove.bg, Photopea, Canva) and save as PNG/WebP.
- Keep text out of the art except the logo. Numbers, level names and button labels stay as real text in the game.
- Check the licence/terms for commercial use before you publish.

## 0. Style lock (send first, with the mockup attached)

> Use the attached image as the style reference for every image I ask for in this chat. Style: bright, glossy 3D casual mobile-game art, like a polished match-3 or merge game. Soft rounded shapes, thick clean outlines in a darker shade of each colour, strong top-left highlight, a soft bottom shadow, saturated candy colours, friendly and cheerful. No text unless I ask for it. Keep the same look, proportions and colour palette as the attached image across all results. Reply "ready" and wait for my next request.

## 1. Background scene

> Using the style reference, paint a full-screen mobile game background, portrait 1024x1536. A bright blue sky with soft white clouds, floating grassy islands with trees, a small blue-roofed tower on the left island and a cream castle with purple roofs and a red flag on the right island. Rolling green hills with a sandy path winding toward the camera in the bottom half, small flowers. Keep the top 30 percent fairly open sky (a logo goes there) and the bottom 40 percent calm grass (buttons go there). No characters, no logo, no buttons, no text, no UI.

Also ask for a taller variant: "Same scene, portrait 1024x2048, extend the sky upward and the grass downward so it fits very tall phones."

## 2. Logo

> Using the style reference, make the game logo "MERGE QUEST" on a solid flat magenta (#FF00FF) background. A glossy 3D golden crown with a red gem sits on top. "MERGE" in white bubble letters with a thick blue outline, "QUEST" below it in golden-yellow bubble letters with a thick dark-purple outline. Under both, a purple ribbon banner with the text "Merge • Match • Win!" in white. Add a few small sparkles. Centered, square 1024x1024, no scene, no characters.

## 3. Characters (one image each, solid magenta background)

> Using the style reference, one cute number-tile character on a solid flat magenta (#FF00FF) background: a glossy blue rounded-square block with the number "2" in white with a dark-blue outline at the top, big friendly eyes with highlights, rosy cheeks and a small open smile at the bottom. Front view, slightly tilted left, soft shadow beneath. 1024x1024, centered, nothing else.

Repeat with: **green "4"** (looking slightly right), **orange "8"** (tilted right), and:

> The same style: a glossy purple rounded-square character with NO number, both arms raised in celebration, big happy eyes and a wide open smile, with little yellow sparkles around it. Solid magenta background, 1024x1024.

Pose variants (for later animation; ask for each character):

> Same character, same size and position, exactly the same except: eyes closed in a happy blink.

> Same character, same size and position, but jumping with a big cheerful open mouth.

## 4. Icon sheet (slice into separate icons afterwards)

> Using the style reference, an icon sheet on a solid flat magenta (#FF00FF) background: 8 separate icons in a 4x2 grid with generous spacing, each about 256x256, no labels. Row 1: a gold coin with an embossed rim; a gold star; a purple gear/settings cog; a gold trophy cup. Row 2: a gold infinity symbol; a gold medal with a blue and red ribbon; a three-bar chart in orange, gold and sky blue; a purple closed book with a white question mark on the cover. Same glossy 3D style, thick outlines, highlight top-left.

Extra icons for later: fire (streak), hammer, swap arrows, undo arrow, gift chest, lock, home, checkmark. Ask for these as a second sheet in the same style.

## 5. Button art (blank, no text)

> Using the style reference, a UI button sheet on a solid flat magenta (#FF00FF) background, no text on any of them: (1) a very wide glossy golden-yellow pill button with a glowing light-yellow rim; (2) a wide rounded purple button; (3) a wide rounded green button; (4) a small square rounded purple dock button; (5) a wide purple bottom dock bar with rounded top corners. Same glossy 3D look with a darker bottom edge for depth.

## 6. Store graphics

App icon:
> Using the style reference, a square mobile app icon, 1024x1024, full bleed (no rounded corners, no border): the cheerful blue "2" character and the green "4" character in front of a bright blue sky with a golden crown above them. No text.

Google Play feature graphic:
> Using the style reference, a wide banner 1024x500 for a game store listing: the "MERGE QUEST" logo on the left, the 2, 4 and 8 characters and the purple character on the right, the floating-island sky background behind. Leave a safe margin on all sides.
